# NDLOCR-Lite 自動ファイル名一括結合ツール

国立国会図書館のOCRツール（NDLOCR-lite 1.3.1）が出力した、ページごとの大量のJSONファイルを、フォルダごとに1つのテキストファイル（.txt）へ一括結合・クレンジングするデスクトップツールです。

ドラッグ＆ドロップによる直感的な操作と、縦書きOCR特有の誤認識を自動修正するフィルター機能を備えています。

## 📌 主な機能
- **簡単ドラッグ＆ドロップ:** 処理したいファイルがあるフォルダ（複数可）を画面にドロップするだけで一括登録。
- **自動ファイル名生成:** 出力されるテキストファイル名は、元の「フォルダ名.txt」として各フォルダ内に自動作成されます。
- **縦書きOCR用クレンジング:** 
  - 不要なスペース（全角・半角）の自動削除。
  - 縦書きで誤認識されやすい「丨」「｜」「\|」を正しい長音符「ー」に自動置換。
  - ページ番号などの数字のみの行を自動スキップ。
  - 行末が句点（。）や閉じ括弧などで終わる場合に、自動で次の行の先頭に全角スペースを挿入して段落を整形。
- **自動環境セットアップ:** 実行時に必要なライブラリ（`tkinterdnd2`）が不足している場合、自動的にバックグラウンドでインストールを行います。

## 🛠 動作環境
- **OS:** Windows / macOS / Linux (Pythonが動作する環境)
- **Python:** 3.x 以降
- **対応データ:** NDLOCR-lite 1.3.1（国立国会図書館OCR）から出力された文字認識結果のJSONファイル
  *(※JSON内の構造によっては、事前にスクリプト内のキー指定の調整が必要な場合があります)*

## 🚀 使い方

### 1. 準備
本ツールは標準ライブラリ以外の依存関係（`tkinterdnd2`）を自動的にセットアップしますが、あらかじめ以下のコマンドで手動インストールしておくことも可能です。
```cmd
pip install tkinterdnd2
```

### 2. ツールの起動
プログラム（例: `ocr_combiner.pyw`）を実行します。
```cmd
python ocr_combiner.pyw
```
あるいはファイラーからocr_combiner.pywをダブルクリック。

### 3. 操作手順
1. 起動すると、ドラッグ＆ドロップ専用のウィンドウが表示されます。
2. NDLOCRのJSONファイル（`0001.json` などの連番ファイル）が格納されている**フォルダ**を、まとめて選択してウィンドウへドラッグ＆ドロップします。
3. ドロップ後、対象のフォルダ件数を確認し、**「一括処理を実行する」** ボタンをクリックします。
4. 各フォルダ内に、フォルダ名と同じ名前の `.txt` ファイルが生成されます。
